# Duckventure (Резиновая утка) — duck.html

Однофайловая HTML-страница без зависимостей (`<title>Duckventure</title>`). Клик по утке → звук, частицы «Кря», проверка ачивок. Слева вверху — кнопка «🏆 Ачивки», открывающая модальное окно со всеми достижениями в 4 столбца. При открытии ачивки над уткой по центру всплывает анимированная карточка.

## Ветки прокачки (Апгрейды)
1. **Возможности**:
   - LVL 1: Открывает автокрякалку и прокачку скорости (60 🦆).
   - LVL 2: Открывает кнопку и модальное окно «Магазин».
   - LVL 3: «Гусыня» — теперь утка несет яйца (10% шанс на обычное 🥚 со звуком вылетающей пробки `corkPopSound`, 0.5% шанс на золотое ✨🥚 со звуком опыта `xpSound` при кликах и автокряканье). Открывает счётчик `#eggsBar`.
   - LVL 4: Переезд — открывает возможность перемещать утку мышкой/тачем. При смещении утки под ней спавнится секретный предмет «Ключ», который добавляется на склад, и разблокируется ачивка «Переезд».
   - LVL 5: «Бизнес» — открывает возможность вести бизнес, постоянный x2 ко всей добыче и кнопку «🏢 Филиалы» справа от склада, открывающую окно филиалов.
2. **Автокрякалка** (требует «Возможности» LVL 1):
   - Доход за тик: +1, +4, +18, +80, +350 🦆.
   - При срабатывании вылетают 3–5 блеклых частиц `spawnAutoQuack` без звука и анимации утки, а также проверяется шанс снести яйцо (`checkEggRoll(false)`).
3. **Скорость** (требует «Возможности» LVL 1):
   - Увеличивает частоту тиков автокрякалки:
     - По умолчанию (LVL 0): 2.0 сек (2000 мс).
     - LVL 1: 1.5 сек (1500 мс).
     - LVL 2: 1.1 сек (1100 мс).
     - LVL 3: 0.8 сек (800 мс).
     - LVL 4: 0.55 сек (550 мс).
     - LVL 5: 0.35 сек (350 мс).
4. **Крит шанс**:
   - Увеличивает шанс нанесения критического удара при клике и его множитель добычи:
     - LVL 1: 5% шанс, x3 множитель (200 🦆, req LVL 2).
     - LVL 2: 10% шанс, x4 множитель (2 250 🦆, req LVL 6).
     - LVL 3: 18% шанс, x5 множитель (27 500 🦆, req LVL 10).
     - LVL 4: 26% шанс, x7 множитель (325 000 🦆, req LVL 15).
     - LVL 5: 35% шанс, x10 множитель (3 500 000 🦆, req LVL 20).
   - При срабатывании крита: проигрывается `critSound()`, вылетает крупная частица `💥 КРИТ! +X 🦆` цвета `#ff3366`.
5. **Сила**:
   - Сила клика: 2, 8, 40, 200, 1000 🦆 за нажатие.

## Как добавить ачивку
1. В массив `ACHIEVEMENTS` (верх `<script>`) добавить объект:

```js
{
  id: 'my-id',            // уникальный id → ключ в localStorage
  name: 'Название',
  desc: 'Описание',
  done: false,
  check: () => condition   // bool, опирается на глобальные переменные, напр. quackCount
}
```

2. Готово. Всё остальное — UI, сохранение, звук, анимация — работает автоматически:
   - порядок в массиве = порядок карточек в списке;
   - `buildAchievementCards()` сам строит карточки в модальном окне ачивок `#achievementsModal` в 4 столбца;
   - после каждого клика `tryUnlock()` проверяет `check()` у не-открытых ачивок;
   - при разблокировке:
     - карточка в модальном окне обновляется в статус `.unlocked`, прячет замок и показывает название/описание;
     - над уткой по центру спавнится карточка уведомления `.achv-toast-card`: `fade-in` (0-350мс) → `Золотое свечение` (350мс) → `звук xpSound и отлет замка поверх плашки как частицы fly` (520мс) → `появление названия и описания` (580мс) → `комфортное чтение` (~3.2 сек) → `fade-out` (3800-4300мс) → `удаление из DOM`.
     - если несколько ачивок открыты одновременно, они отображаются рядом друг с другом без наложения.
     - если ачивка была получена вне основного окна (в любом открытом модальном окне, например при клике на закрытую карточку в ачивках), все модальные окна принудительно закрываются (`closeAllModals()`), возвращая игрока на основной экран для просмотра анимации.

Клик по заголовку плавно сворачивает/разворачивает соответствующий список товаров независимо друг от друга. Состояние сворачивания сохраняется в `localStorage` (`duck-shop-clothing-collapsed`, `duck-shop-household-collapsed`).

При наведении курсора карточка плавно осветляется (`opacity: 0.85`), сохраняя читаемость.

     - Игрок выкладывает купленную Напольную лампу со склада на стол.
     - На лампе доступна интерактивная кнопка `#lampToggleBtn` (💡), переключающая свет с механическим звуком `lampSwitchSound(on)`.
     - При включении лампа подсвечивается золотым фильтром, а по краям экрана появляется тёплое янтарное свечение (`#lampWarmGlowOverlay` с мягким дыханием `@keyframes lampWarmBreathe`).

       - Проигрывается звук жарки `sizzleSound()` и вылетают частицы огня/дыма.
       - Открывается новая валюта жареных яиц в `#eggsBar` и карточки продажи в магазине (до первой прожарки скрыты).
        - На столе возле плиты спавнится перетаскиваемое эмодзи жареного яйца (одно эмодзи на столе для каждого существующего типа; если эмодзи уже выложено на столе, после последующих жарок его позиция сохраняется и не перезаписывается).
        - **Жареные яйца не могут быть разбиты** (механика броска smashEgg работает строго на сырых яйцах).
       - Разблокируется ачивка «Прожарка».

## Пауза игры в модальных окнах
- При открытии любого окна (`#upgradesModal`, `#shopModal`, `#wardrobeModal`, `#storageModal`, `#branchesModal`, `#achievementsModal`) срабатывает `isAnyModalOpen()`:
  - Тики автокрякалки (`autoQuackTimer`) приостанавливаются (нет начисления пассивного дохода, нет спавна частиц автокряка и проверки выпадения яиц).
  - Клики по утке и таймер зависания курсора игнорируются.
  - Нажатия клавиш геймплея не обрабатываются; по клавише **Escape** активное окно закрывается.
  - Список улучшений не пересоздаётся в DOM при начислении валюты, предотвращая срыв кликов по кнопкам прокачки и мигание интерфейса.
  - При закрытии окна игра возобновляется, подсветка кнопки апгрейдов обновляется.

## Сохранение
`localStorage`:
- ачивки: ключ `duck-achv-{id}`, значение `'1'`;
- счётчики и флаги: `duck-quack-count`, `duck-duckles`, `duck-hint-count`, `duck-key-pressed`, `duck-seq-done`, `duck-locked-clicked`, `duck-devtools`, `duck-bad-words`, `duck-hover-wait`, `duck-moved-duck`, `duck-spawned-key`, `duck-has-smashed-eggs`, `duck-pos`;
- яйца: `duck-eggs-normal`, `duck-eggs-golden`;
- система уровней и апгрейдов: `duck-level`, `duck-level-exp`, `duck-upg-autoquack`, `duck-upg-speed`, `duck-upg-crit`, `duck-upg-strength`, `duck-upg-features`;
- скины и гардероб: `duck-owned-skins` (JSON-массив), `duck-current-skin` (строка id);
- магазин: состояние свёрнутых секций `duck-shop-clothing-collapsed`, `duck-shop-household-collapsed`;
- склад и предметы: `duck-owned-props` (JSON-массив), `duck-placed-props` (JSON-словарь `{ id: { left, top } }`), `duck-lamp-on` (состояние включенного света торшера/лампы);

При загрузке страницы статус ачивок, уровни, яйца, улучшения, гардероб, предметы, позиция утки и состояние тараканов считываются из storage.

## Звуки (Web Audio API, без файлов)
- `quack()` — «кря»: sawtooth + square + шумовой burst.
- `xpSound()` — опыт/левелап: восходящий арпеджио из 5 нот (523→1046 Гц, square). Проигрывается при ачивках, левелапе, продаже яиц и **появлении золотого яйца**.
- `corkPopSound()` — хлопок/«пук» пробки от шампанского (свип 620→75 Гц + полосовой шум). Проигрывается при **появлении обычного яйца**.
- `critSound()` — звонкий восходящий крит-звук (620→1250 Гц, triangle). Проигрывается при **критическом клике**.
- `clinkSound()` — металлический щелчок соединения плиты и сковороды (1400→750 Гц sine).
- `sizzleSound(isGolden)` — шипение/жарка яиц на сковороде (белый шум + полосовой фильтр 2800/3800 Гц).
- `spraySound()` — шипение распыления дихлофоса (белый шум + полосовой фильтр 2200 Гц с модуляцией LFO и огибающей громкости на 2.5 сек).
- `splatSound()` — звук разбития яиц (шумовой хруст скорлупы 1400 Гц + влажный шмяк 420→75 Гц).
- `lampSwitchSound(on)` — переключение напольной лампы: реалистичный механический щелчок тумблера + тёплый резонанс синусоиды (включение 580→920 Гц, выключение 720→420 Гц).

## Физика частиц
- `spawn(x, y)` — 8–15 частиц за раз (+10%); угол 0–180° (вверх), скорость 90–470 px/s, альфа 0.18–0.90.
- `spawnAutoQuack(x, y)` — 3–5 частиц при автокряке; более прозрачные (альфа 0.10–0.30), скорость 70–290 px/s, без звука и попа утки.
- Критические частицы: `💥 КРИТ! +X 🦆`, размер 24–26, яркий цвет `#ff3366`.
- Гравитация `GRAVITY = 1000 px/с²`; `dt` ограничен 50 мс.
- Частица удаляется при вылете за экран.
- **Оптимизация фонового режима (лаги исключены)**: когда вкладка или окно браузера не в фокусе (`document.hidden || !document.hasFocus()`), частицы не создаются (в `spawn`, `spawnAutoQuack`, `spawnLvlUp`), а при сворачивании массив частиц очищается. При этом начисление Даклей (`addDuckles`) и механика яиц продолжают работать в фоне на полной скорости. Ограничение массива частиц в кадре — максимум 200.

  3. удаляет `duck-achv-{id}` (кроме `duck-achv-monster`), `duck-level`, `duck-level-exp`, `duck-eggs-*`, `duck-fried-eggs`, `duck-golden-fried-eggs`, `duck-has-fried-eggs`, `duck-cooked-egg`, `duck-stove-combined`, `duck-placed-fridge`, `duck-roaches-active`, `duck-used-dichlofos`, `duck-cleared-roaches`, `duck-gta-cheat`, `duck-beast-number`, `duck-moved-duck`, `duck-spawned-key`, `duck-pos`, `duck-has-smashed-eggs`, `duck-upg-*`, `duck-owned-skins`, `duck-current-skin`, `duck-owned-props` и `duck-placed-props` из localStorage;

  6. обновляет отображение Даклей, полосу и плашку уровня (`updateLevelDisplay()`), сбрасывает таймер автокрякалки, скрывает кнопку Магазина, Гардероба и Склада (`updateShopButtonVisibility()`), блокирует вкладку продажи яиц (`updateShopTabsVisibility()`) и обновляет карточки улучшений (`renderUpgrades()`).
- **Из окна Game Over (`#cookedDuckRestartBtn`)** → `restartFromCookedDuck()` / `resetAchievements(true)`:
  - Сбрасывает игровой прогресс (валюту, уровень, яйца, предметы на столе, прокачку), но **полностью сохраняет все ранее открытые ачивки** в `localStorage` и памяти, а также разблокирует вечную ачивку «Ты монстр!».

## Подводные камни (Pitfalls)
1. **HTML карточки собирается конкатенацией — потерянная кавычка молча ломает DOM.**
   `'<div … id="achv-info-\' + a.id + \' aria-live="polite">'` (без `"` после `a.id`) браузер читает как `id="achv-info-{id} aria-live="` → `getElementById('achv-info-{id}')` → `null`.
   - Симптом: после перезагрузки всё ок, но при живом открытии текст остаётся `opacity: 0` до перезагрузки (замок отлетает, карточка жёлтая — эти строки **до** сломанной); ошибка в консоли тихая (внутри `setTimeout`).
   - Проверка: после `buildAchievementCards()` убедись, что в DOM `id === "achv-info-{id}"` и есть класс `achv-info` (с `.shown`).
2. **`class` и `id` — разные вещи.** Опечатка в `id` не мешает вписать `shown` в строку класса → типичный симптом: «работает после перезагрузки, но текст не появляется при живом разблокировании».
3. **При сбросе обнуляй счётчики, а не только storage.** `check()` использует живые счётчики.
4. **Все стили объединены в единый блок `<style>` в `<head>`.** Не добавляй разрозненные `<style>` в середину `<body>`.
5. **Все переменные состояния и таймеры (`audioCtx`, `autoQuackTimer`, `hoverTimer` и т.д.) объявляй вверху скрипта.** Если объявить переменную через `let` ниже функций или вызвать функцию до объявления переменной, браузер выбросит ReferenceError из-за временной мёртвой зоны (TDZ), и скрипт полностью упадёт (перестанут работать клики и слушатели событий). Все стартовые вызовы (`buildAchievementCards()`, `updateDuckles()`, `tryUnlock()` и т.д.) должны находиться в самом низу скрипта.
6. **После каждого изменения кода обнови этот файл.** Устаревшие секции («текущие ачивки», счётчики, кнопки) вводят следующего агента в заблуждение.
