# Резиновая утка — duck.html

Однофайловая HTML-страница без зависимостей. Клик по утке → звук, частицы «Кря», проверка ачивок. Слева — панель ачивок.

## Ключевые элементы
| Элемент | Назначение |
|---|---|
| `#duck` | Кнопка-утка (центр). Клик: `pop`-анимация, звук, частицы, `quackCount++`, `duckles++`, `tryUnlock()` |
| `#ducklesBar` / `.duckles-val` | Верхняя плашка баланса валюты («Даклей заработано: X») |
| `#upgradesBtn` / `#upgradesModal` | Кнопка «⚡ Апгрейды» и модальное окно прокачки (3 ветки по 5 уровней) |
| `#lvlBox` / `#lvlNum` / `#lvlBarFill` | Система уровней в правом нижнем углу (LVL 1..99 + полоса опыта) |
| `#particles` | Canvas поверх всего. Частицы: текст «Кря» (случайный HSL), `fly` (эмодзи 🔒) и `LVL UP!` (жёлтый) |
| `#achvList` / `.achv-card` | Карточки ачивок слева. Серое окно = не открыта (🔒, текст скрыт); `.unlocked` = жёлтая подсветка + свет |
| `quackCount` / `duckles` / `hintCount` / `playerLevel` / `playerExp` | Глобальные счётчики: клики, валюта, подсказка, уровень и опыт |
| `upgradeLevels` | Уровни купленных улучшений (`autoquack`, `strength`, `features`) |
| `keyPressed` / `duckSeqDone` / `lockedCardClicked` / `devToolsOpened` / `badWordsTyped` / `hoverWaitDone` | Флаги для клавиатурных, скрытых и таймерных ачивок |
| `particles` | Глобальный массив частиц |
| `audioCtx` | AudioContext, создаётся ленью |
| `GRAVITY` | 1000 px/с² |
| `#resetBtn` / `.reset-btn` | Кнопка «Начать заново» (правый верхний угол) → `resetAchievements()` |
| `.hint` («Жмякни крякалку») | Мнимая надпись внизу; клик по ней → `hintCount++` + `tryUnlock()` (не по утке) |

## Как добавить ачивку
1. В массив `ACHIEVEMENTS` (верх `<script>`) добавить объект:

```js
{
  id: 'my-id',            // уникальный id → ключ в localStorage
  name: 'Название',
  desc: 'Описание',
  done: false,
  check: () => condition   // bool, опирается на глобальные переменные, напр. quackCount
}
```

2. Готово. Всё остальное — UI, сохранение, звук, анимация — работает автоматически:
   - порядок в массиве = порядок карточек в списке;
   - `buildAchievementCards()` сам строит карточки;
   - после каждого клика `tryUnlock()` проверяет `check()` у не-открытых ачивок;
   - при разблокировке: `xpSound()` (звук опыта из Minecraft), жёлтая подсветка карточки (`.unlocked`) + анимация `flash`, появление названия/описания (`.shown`, 220 мс), замок 🔒 отлетает с карточки как частица `fly`.

## Сохранение
`localStorage`:
- ачивки: ключ `duck-achv-{id}`, значение `'1'`;
- счётчики и флаги: `duck-quack-count`, `duck-duckles`, `duck-hint-count`, `duck-key-pressed`, `duck-seq-done`, `duck-locked-clicked`, `duck-devtools`, `duck-bad-words`, `duck-hover-wait`;
- система уровней и апгрейдов: `duck-level`, `duck-level-exp`, `duck-upg-autoquack`, `duck-upg-strength`, `duck-upg-features`.
При загрузке страницы статус ачивок, уровни и улучшения считываются из storage.

## Звуки (Web Audio API, без файлов)
- `quack()` — «кря»: sawtooth + square + шумовой burst.
- `xpSound()` — опыт: восходящий арпеджио из 5 нот (523→1046 Гц, square).

## Физика частиц
- `spawn(x, y)` — 8–15 частиц за раз (+10%); угол 0–180° (вверх), скорость 90–470 px/s, альфа 0.18–0.90.
- Гравитация `GRAVITY = 1000 px/с²`; `dt` ограничен 50 мс.
- Частица удаляется при вылете за экран.

## Сброс прогресса («Начать заново»)
`#resetBtn` (правый верхний угол). Клик → `resetAchievements()`:
1. обнуляет глобальные счётчики и флаги (`quackCount = 0`, `duckles = 0`, `hintCount = 0`, `playerLevel = 1`, `playerExp = 0`, `upgradeLevels = { autoquack: 0, strength: 0, features: 0 }`, `keyPressed = false`, `duckSeqDone = false`, `lockedCardClicked = false`, `devToolsOpened = false`, `badWordsTyped = false`, `hoverWaitDone = false`, `duckSeqIndex = 0`), очищает таймер ожидания и удаляет все ключи из `localStorage`;
2. ставит `done = false` у всех ачивок;
3. удаляет `duck-achv-{id}`, `duck-level`, `duck-level-exp` и `duck-upg-*` из localStorage;
4. перестраивает карточки через `buildAchievementCards()`;
5. обновляет отображение Даклей, полосу и плашку уровня (`updateLevelDisplay()`), сбрасывает таймер автокрякалки и обновляет карточки улучшений (`renderUpgrades()`).

## Подводные камни (Pitfalls)
1. **HTML карточки собирается конкатенацией — потерянная кавычка молча ломает DOM.**
   `'<div … id="achv-info-\' + a.id + \' aria-live="polite">'` (без `"` после `a.id`) браузер читает как `id="achv-info-{id} aria-live="` → `getElementById('achv-info-{id}')` → `null`.
   - Симптом: после перезагрузки всё ок, но при живом открытии текст остаётся `opacity: 0` до перезагрузки (замок отлетает, карточка жёлтая — эти строки **до** сломанной); ошибка в консоли тихая (внутри `setTimeout`).
   - Проверка: после `buildAchievementCards()` убедись, что в DOM `id === "achv-info-{id}"` и есть класс `achv-info` (с `.shown`).
2. **`class` и `id` — разные вещи.** Опечатка в `id` не мешает вписать `shown` в строку класса → типичный симптом: «работает после перезагрузки, но текст не появляется при живом разблокировании».
3. **При сбросе обнуляй счётчики, а не только storage.** `check()` использует живые счётчики.
4. **Все стили объединены в единый блок `<style>` в `<head>`.** Не добавляй разрозненные `<style>` в середину `<body>`.
5. **Переменная `audioCtx` должна быть объявлена вверху скрипта.** Если объявить `audioCtx` через `let` ниже функций `quack()` / `xpSound()`, можно словить ошибку временной мёртвой зоны (TDZ) при раннем вызове.
6. **После каждого изменения кода обнови этот файл.** Устаревшие секции («текущие ачивки», счётчики, кнопки) вводят следующего агента в заблуждение.
